プライバシーポリシー

Hermes Agent(以下「本アプリ」)は、運営者(雨傘てれるん)本人のみが自分のGoogleアカウントに対して利用する個人用アプリです。

取得する情報

本人が認可したGoogleアカウントのGmail、カレンダー、Drive、Docs、Sheets、連絡先のデータにアクセスします。

利用目的

メールの確認、予定の確認、下書き作成など、運営者本人の作業補助のみに利用します。

保管・共有

認証トークンは運営者の管理するサーバー内にのみ保存します。取得したデータを第三者へ提供・販売・広告利用することはありません。Google API Services User Data Policy(Limited Use要件を含む)に準拠します。

削除

Googleアカウントの設定から、いつでも本アプリのアクセス権を取り消せます。
